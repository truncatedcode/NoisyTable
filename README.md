# NoisyTable

Noisy Table is a Unity project for a VRChat world or asset.

## Project

- Unity: `2022.3.22f1`
- VRChat SDK: Worlds `3.10.3`

## Setup

Open the project through VRChat Creator Companion so VCC can restore the VRChat packages listed in `Packages/vpm-manifest.json`.

Unity-generated folders such as `Library/`, `Temp/`, `Obj/`, `Logs/`, and generated package folders are intentionally ignored.
